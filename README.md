In this repository you will find IARU R1 VHF+ band plan available in easy format that you can you use to code your own library.

You can download the bandplan directly [here](https://github.com/IARU-R1-C5/bandplan/raw/refs/heads/official/bandplan.json)

This repository is going to be updated after each bandplan change.

Current band plan is based on official: [VHF HandBook V10_03](https://www.iaru-r1.org/wp-content/uploads/2024/11/VHF_Handbook_V10_03_final.pdf) as of February 2026.

Work in progress.
